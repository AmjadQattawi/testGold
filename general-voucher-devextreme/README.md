# General Voucher — DevExtreme

مشروع React وTypeScript مستقل مستوحى من صفحة JournalVoucher في المشروع الأساسي. جميع عناصر الإدخال والأزرار والجدول والنوافذ والإشعارات بمكونات DevExtreme، بواجهة إنجليزية واتجاه LTR مطابقين للصورة المرجعية.

## التشغيل

```powershell
cd general-voucher-devextreme
npm install
npm run dev
```

العنوان: http://127.0.0.1:5174

```powershell
npm run build
npm test
```

## الاستخدام

تُعرض حقول الأسطر مباشرة مثل الصفحة الأصلية. يبدأ السند بسطر فارغ ويضاف سطر جديد تلقائيًا عند اكتمال السطر الأخير. تعرض الإجماليات تحت الأعمدة وتحسب على كامل السند حتى عند التصفية. يمكن تحديد الأسطر وحذف المحدد، بما فيه تحديد الأسطر الظاهرة فقط.

تستخدم الصفحة فلاتر DevExtreme DataGrid الأصلية: HeaderFilter لاختيار القيم والبحث فيها، وFilterRow لشروط النصوص والأرقام والتواريخ (بما فيها between)، وFilterPanel لبناء شروط مركبة ومسحها. لإظهار صف الشروط انقر بزر الفأرة الأيمن على رأس العمود واختر Show filter row؛ الصف مخفي افتراضيًا لمطابقة الصورة. الفرز مدمج في رؤوس الأعمدة. لم تعد هناك واجهة أو خوارزمية تصفية مخصصة.

حفظ المسودة يسمح بالمسودات غير المتوازنة كما في الأصل، ويمنع تعارض المدين والدائن أو إدخال مبلغ دون حساب. الترحيل يتحقق من السند والتوازن ويعرض أن API غير مربوط؛ لا ينفذ ترحيلًا فعليًا.

يشمل الحفظ المحلي والبحث المضمن بالرقم أو الملاحظات وفتح السندات والتنقل للأول والسابق والتالي والأخير والأرشفة والحذف واستعادة النسخة المحفوظة والطباعة. الأرشفة علامة على المسودة كما في الأصل. الخروج يعرض مدخلًا محليًا للعودة لسند القيد لأن المشروع مستقل عن واجهة النظام الرئيسية.

الحسابات ومراكز التكلفة بيانات تجريبية. الحفظ في localStorage مستقل عن المشروع الأساسي ولا يرسل بيانات إلى خادم، ولا ينفذ ترحيلًا محاسبيًا. يجب ربط API وإعادة التحقق في الخادم قبل استخدامه للإنتاج. يتطلب استخدام DevExtreme ترخيصًا مناسبًا من DevExpress؛ يمكن أن تظهر رسالة التقييم دون مفتاح الترخيص.


## تنظيم المشروع

```text
src/
  main.tsx                         # تهيئة التطبيق واللغة والثيم
  pages/JournalVoucher.tsx          # تجميع مكونات الصفحة
  hooks/useJournalVoucher.ts        # حالة السند والإجراءات والتحقق
  services/voucherDraftStorage.ts   # قراءة وكتابة المسودات
  utils/voucher.ts                  # الأنواع وإنشاء السند والأسطر
  utils/validation.js               # قواعد التحقق والإجماليات
  components/voucher/
    VoucherInfo.tsx                 # بيانات السند
    VoucherDetails.tsx              # DataGrid وفلاتره الأصلية
    VoucherCell.tsx                 # حقول خلايا الجدول
    voucherColumns.ts              # تعريف الأعمدة
    VoucherDraftSearch.tsx          # بحث المسودات
    VoucherToolbar.tsx              # أزرار الإجراءات
  styles.css                       # تنسيق الصفحة والجدول
```

## مطابقة تصميم testGold

النسخة الحالية تستخدم ملفات الخط الأصلية وأيقونات `VoucherIcon` نفسها من testGold. تتبع نسب الأعمدة الأصلية 4/9/9/20/8/11/9/8/19 مع 3% للتحديد. جميع المحررات والأزرار والجدول مكونات DevExtreme، مع تنسيق مخصص ليتوافق مع الصورة المرجعية. تم توحيد ارتفاع قسم البيانات والصفوف والإجماليات وشريط الإجراءات ومراجعتها عند 1575 × 801.
